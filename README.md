# CosmosHub - Blog Científico

Um blog científico moderno e interativo sobre astronomia e o universo, focado em trazer conhecimento de forma dinâmica e envolvente.

## 🚀 Tecnologias

Este projeto foi construído utilizando as seguintes tecnologias:
- **[Vue 3](https://vuejs.org/)**: Framework JavaScript progressivo para construção da interface de usuário.
- **[Vite](https://vitejs.dev/)**: Ferramenta de build e servidor de desenvolvimento super rápido.
- **[Tailwind CSS v4](https://tailwindcss.com/)**: Framework CSS utility-first para estilização rápida, moderna e responsiva.
- **[Lucide Icons](https://lucide.dev/)**: Biblioteca de ícones elegantes, implementada via `lucide-vue-next`.
- **[tsParticles](https://particles.js.org/)**: Biblioteca para criação do fundo animado com partículas espaciais (`@tsparticles/vue3`).
- **[Vercel Speed Insights](https://vercel.com/docs/speed-insights)**: Ferramenta integrada para o monitoramento da performance web.

## 📦 Como rodar o projeto localmente

Para rodar este projeto em sua máquina local, certifique-se de ter o [Node.js](https://nodejs.org/) instalado na versão suportada: `^20.19.0` ou `>=22.12.0`.

1. **Acesse a pasta do projeto:**
   ```bash
   cd Blog-Cient-fico/blog-cientifico
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. **Abra no seu navegador:**
   O terminal exibirá uma URL (normalmente `http://localhost:5173/`). Clique no link ou copie e cole no navegador para visualizar o projeto.

## 🛠️ Scripts Disponíveis (package.json)

- `npm run dev` - Inicia o servidor de desenvolvimento local.
- `npm run build` - Gera os arquivos estáticos e otimizados da aplicação para produção.
- `npm run preview` - Inicia um servidor local para que você possa pré-visualizar o projeto após o build de produção final.

## 🌌 Estrutura Principal

A aplicação possui um layout construído majoritariamente em Single-Page ("Página Única") dividida por seções e componentes Vue, incluindo:
- **Hero:** Capa de apresentação do blog, com tipografia chamativa ("Explorando o Universo") e fundo animado;
- **Sobre:** Descrição a respeito da intenção e detalhes da página;
- **Marte:** Seção temática focada em informações do planeta Marte;
- **Artigos:** Local para leituras sobre as descobertas astrofísicas;
- **Eventos:** Calendário ou listagem dos próximos eventos relevantes de astronomia;
- **Contato:** Informações e canais em que o usuário possa se comunicar.
